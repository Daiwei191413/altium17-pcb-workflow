# AD17 射频 EVB 设计与复查

## 原理图先画出测试条件

沿“仪器端口 → 隔直或匹配 → 芯片脚号”追踪输入和输出。记录频段、源和负载阻抗、供电、偏置时序、输出功率的定义及测试点。使用该器件、该频段和封装的原厂应用图确定匹配初值。用户给的另一型号参考板也可用于学习画法，记录它支持的具体决定。

- 用户希望两路共用供电插针时，核对电压范围、时序、回灌和分开调试的要求。条件相容时共用电源入口，原图中有独立串联件和就地去耦的支路仍逐脚保留。区分主电源与偏置电源。
- 外部信号源经 SMA 和无源网络激励输入时，ERC 可能报无驱动源。从连接器中心针一路查到芯片脚，在编译记录旁写明激励来源和端点。若发现断路、供电脚浮空或真实驱动冲突，按连接问题修正。保持符号引脚的真实电气类型。
- 固定连接器前核对具体料号、配套图纸、夹持板厚、安装面、中心针和外壳脚。逐端点对网表时，同时记录逻辑脚数和实体焊盘数。一个 SMA 外壳脚号可以对应多个实体地焊盘。

## 宽馈线与接地回流

1. 先标出需要控阻的均匀端口段、SMA 发射端过渡和芯片匹配区。对均匀段记录走线层、连续参考层、成品线宽 W、铜边到同层地的净距 S、走线到参考面的介质厚度 H、材料 Dk、铜厚和阻焊假设。用户未指定板厂时将选用的公开叠层标为设计假设，写明来源与待确认工艺。
2. 用户同时要求线宽和目标阻抗时，按候选叠层求解 W/S。在成品公差或材料未知时记录敏感度。将板厂、叠层、输入、单位、模型与结果一起留档。均匀段使用针对端口网络的 AD17 规则，芯片端匹配段依参考拓扑和焊盘几何处理。
3. 从保存后的 Track 对象读取实际宽度，从铜边量侧隙，沿整段查看参考面投影。变更 SMA、板框或地铜后复查过渡与回流。遇到可编辑的实铜 Region，要检查边界是否已同步，重铺 Polygon 只更新多边形铺铜。
4. 查地孔时沿“元件地焊盘 → 短而宽的表层铜 → 过孔环 → 实际参考层”逐段检查。优先看 SMA 外壳、并联匹配件、去耦和 QFN 裸焊盘。再按板边、剩余大块地铜和装配间距补孔。裸焊盘热孔另核填孔、盖铜和吸锡。数量、排布形状及线宽由本板回流和工艺决定。

## 整板丝印复查

先在目标 PCB 拾取箭头对象，记录位号、图层、对象类型、方向和用途。分别单显 Top Overlay、实际装配层，再叠加查看。黄色可以同时来自两层。先在实物丝印层看调板所需的位号、方向和极性，再在装配层看框内料值、DNP 及芯片型号。装配层编号随工程而异。

| 容易漏掉的位置 | 如何核对 |
| --- | --- |
| 旋转或镜像、换尺寸或不装的同族器件 | 用全板位号做母表，覆盖各摆放方向、同库封装的实例差异和两面贴装。用户只指定几个位号时可汇报其他命中。用户要求清理整类时一并处理。 |
| 成对短线、独立短线和 1 脚标记外形相似 | 对照库内局部坐标、板上旋转/镜像、方焊盘、倒角及极性。区分无用途的附加线、正常边框、方向标志和板级自由图元。仅凭长度或颜色批量删除会误伤装配信息。 |
| 一处改好，更新封装后又出现 | 分别比较工程库定义和板上实例。模板本身带问题时同步修正工程库。个别实例的避让应保留。检查同一模板在所有放置位置的效果。 |
| DRC 为零，目视仍难以对应 | 核对 DRC 中丝印到丝印、丝印到阻焊的实际阈值。按整板和最密集区域两种尺度看位号是否就近对应、方向是否便于阅读、框内能否区分料值和不装件。 |

**AD17 顶层直线清点工具。** 打开目标 PCB，从 **DXP → Run Script** 选择 [OverlayInventory.PrjScr](../scripts/OverlayInventory.PrjScr)，运行 `ExportTopOverlayInventory`。脚本只读当前板，在 D 盘板文件旁写出 CSV。其他盘的输入默认输出到 `D:\Codex\Projects`。同名结果自动编号。

每个器件均有一条 `component` 计数行，包括零条的器件。`member` 行记录封装内顶层丝印直线，`free` 行记录板级自由直线。端点和线宽使用 AD 内部坐标（10,000 单位为 1 mil）。在 AD17 中枚举后要再核对象自身的 `Layer`，单靠迭代器的图层过滤可能把装配外框算进去。直线清单用于定位候选。文字、圆弧、区域、底层丝印、装配层及库定义另按项目需要复查。具体处置回写到逐件清单。

用户指定成板闭合框时，转到[制板包逐件验收](fabrication-silkscreen.md)。上述清点结果可定位源对象，制造外框的闭合和净距需在实际输出层回读。

## 保存后验收

用目标工程重开原生文档，核对工程成员和可编辑对象。丝印类修改前后按网络和几何比较元件位置、焊盘、过孔、布线及地铜，确认差异与本次授权相符。保留已分类图元计数、例外和原生 DRC，给需要分享实操的用户保存整板与关键局部真截图。项目留存的求解值、板厂阻抗条 TDR、样板回波/功率/温升分别标明来源与状态。
