# 从制板包验收器件丝印

## 布局时先留出印线的位置

读用户参考图时分别记录制造外框、位号、方向标志和框内料值的用途。用户要求印到实物的图形放在对应面的 Overlay，同时查看 Gerber 导出任务的层映射。装配框、料值与编辑器配色在装配图中单独处理。

需要独立闭合框时，用器件全部同面焊盘的**阻焊开窗边缘**估算空间。两颗器件共用一条边，最小开窗净距为两侧各自的丝印避让量与一条线宽之和。若要画两条独立边，还要加上第二条线宽以及两条丝印之间的净距。距离足够后再检查转角、位号、板边和方向标记。例如两侧各需 0.254 mm、线宽 0.150 mm 时，共用一条边至少需要 0.658 mm。工艺值取本板规则。

距离不足时，先尝试移位号和使用获准的共边。保留每颗器件的闭合格，两个器件只被一个大框包起来算作组框。若需移动器件或射频匹配支路，沿用用户对本次改版的授权范围，另存板版次。同步修订通用封装库和需要单独避让的板上实例。

## 在交付 ZIP 上逐件复核

1. 以保存并重开的目标 PCB 为位号母表。注明哪些器件需要闭合、哪些需要保持特定开口、哪些采用测试焊盘等免框形式。单独列出自由丝印及方向标记。
2. 使用**待交付 ZIP** 中的实际制造丝印和同面阻焊开窗，检查两层单位、原点、朝向与导出范围。按器件逐个沿实际线段走一圈，确认闭合边界独立包住全部本器件开窗；只包住中心点、断在拐角或捎带邻件均需复查。允许共边时，两侧都要形成闭合格。
3. 量框线外沿与最近开窗的净距，再从 CAM 顶面图复核位号的归属、可读性、方向标记和边缘开口。输出应闭合数、实际闭合数、未通过的位号，以及每项例外对应的几何和理由。保留整板图和密集区局部图。
4. 若移动了焊盘、走线、地孔或实铜区域，重跑同版 AD17 批量 DRC，并用四层或实际全部铜层与镀孔重建导通，逐端点核对编译网表。复查主电源与去耦末端、RF 均匀段的宽度和侧隙、连续参考地与局部回流。记录制板包与原板的对应关系，把待样机验证的项目写进交接。

## 制板包与复核证据

从同一版已保存的 PCB 运行 Gerber 和 NC Drill 输出。对照 AD17 的层扩展报告挑选实际加工所需的文件，逐一注明铜层物理顺序、上下阻焊、实际有内容的丝印、唯一成型轮廓及镀孔／非镀孔。只在订购相应工序时加入钢网资料。保留装配图另供装配查阅，防止板厂把装配框和料值识别为印刷层。

在交付 ZIP 上查中心线板框是否闭合、尺寸是否正确，核对钻孔单位、零抑制、层对、坐标和孔径；叠看夹板接口、两面外壳焊盘和板边。记录源 PcbDoc 的 SHA-256，以及实际检查的 ZIP 文件名和摘要。保留该版 DRC 报告、整板及密集区 CAM 预览、逐件检查表。若几何、布局或导出选层再有变化，更新对应的文件和证据。射频板的叠层与阻抗公差、夹板接口的成品板厚配合、裸焊盘盘中孔工艺分别交给板厂确认。

## 直线外框检查工具

在 AD17 用目标工程打开已保存的 PCB。从 **DXP → Run Script** 加载 [OverlayInventory.PrjScr](../scripts/OverlayInventory.PrjScr)，运行 `ExportTopPadCenters`。CSV 按顶面器件记录顶面及多层实体焊盘，保留相同引脚编号的不同焊盘。坐标相对 PCB 用户原点，单位为 AD 内部坐标。Gerber 输出使用同一相对原点和顶视方向。需要检查底面时，另从底面器件母表和对应的制造层复核。

在技能根目录运行 [audit_gerber_frames.py](../scripts/audit_gerber_frames.py)。此工具用 Gerbonara 和 Shapely；原有网表检查工具仍只需 Python 标准库。以下为本案的运行示例，使用时替换文件、工艺参数和人工核对位号。

```powershell
python -m pip install gerbonara==1.5.0 shapely==2.2.0
python scripts/audit_gerber_frames.py board.zip board_TopPads.csv frames.csv --width-mm 0.15 --clearance-mm 0.254 --manual J1 J2 TP1 TP2 TP3 TP4 TP5
```

默认在 ZIP 中选择唯一的 `.GTO` 和 `.GTS`。其他命名可用 `--silk-member` 和 `--mask-member` 指定完整成员名。AD17 在本地代码页保存含中文字段的 CSV 时可加 `--encoding gbk`。结果写入新的 CSV 文件。

工具从所选线宽的正极性直线图形重建轮廓，把焊盘中心匹配到同一制板包的圆形或矩形开窗，再检查完整开窗几何、邻件归属和框线净距。线宽匹配允许 0.0005 mm 的导出舍入误差。中心线端点按实际 Gerber 坐标拼接。采用圆弧框、混合线宽、复杂阻焊图形、拼板或不同原点时，用支持该图形的 CAM 流程做等价复核。自动结果还需与封装用途、方向标记和位号对应。

| 返回码 | 如何处理 |
| --- | --- |
| 0 | 自动范围内全部闭合且净距满足输入值。逐项完成 `manual` 位号的人工作业后再汇总。 |
| 1 | 有 `open_or_unverified` 或 `clearance_failed`。从 CSV 定位到具体位号，查看实际丝印和开窗。 |
| 2 | 本次检查未完成。核对输入、依赖、坐标原点、层名、极性、几何类型和输出路径。 |

本案的人工项为 J1、J2 靠板边的夹板 SMA，以及 TP1–TP5 的圆形测试点。前两件逐一核对三个印刷边和板边开口方向，后五件核对测试点身份、可探测开窗和位号。新工程按实际结构和用户意图建立例外表。
